# SpamFilter
developing a custom spam filter pipeline consisting of basic analysis, classical ML model checking and LLM-based determination

реализовано:
  - ML микросервис с gRPC сервером

в планах:
  - REST API для запросов на проверку текста / писем с выбором формата
  - отдельный эндпоинт для отправки фидбеков (верно ли предсказано)
  - микросервис для перепроверки неоднозначных ответов (если прогноз классики где-то между 0.4 и 0.5) через публичную LLM (например LLama)
  - внедрение Redis и системы репутации для почт (если у почты пользователя отрицательный рейтинг, сразу отправлять ответ, не нагружая модель)
  - postgresql для хранения истории и дообучения на новых ответах
